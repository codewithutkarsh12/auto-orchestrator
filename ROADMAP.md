# Roadmap

## Phase 1 — Core (current)
- Task decomposition baseline
- Skill registry and router
- Dependency-aware pipeline
- Context/token budget
- Unit tests and security docs

## Phase 2 — Model adapters
- Provider-neutral analyzer interface
- Structured output validation
- Retry policy with bounded attempts
- Evaluation corpus for decomposition and routing

## Phase 3 — Skill ecosystem
- Declarative skill manifest schema
- Compatibility and provenance checks
- Signed release metadata
- Community catalog with review workflow

## Phase 4 — Integrations
- MCP adapters with explicit allowlists
- User confirmation for consequential actions
- Audit logs with secret redaction

## Phase 5 — Production readiness
- Sandboxing and resource limits
- Observability and run replay
- Security review and threat model
- Stable API and versioning policy
